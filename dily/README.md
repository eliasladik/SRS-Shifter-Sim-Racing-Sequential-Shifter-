# Díly

Sem patří soubory k mechanickým/elektronickým dílům řadičky, např.:

- 3D modely (`.stl`, `.step`) pro tisknuté/frézované díly těla řadičky
- výkresy
- datasheety k použitým součástkám (mikrospínače, Pro Micro, konektory...)

Doporučená struktura, jak přibudou soubory:

```
dily/
├── 3d-tisk/
├── vykresy/
└── datasheety/
```
